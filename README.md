# 歴史 年号クイズ（PWA）

中学受験の歴史（年号・できごと・人物）を4択で練習するウェブアプリです。
iPhone のホーム画面に追加すると、アプリのように全画面で起動し、オフラインでも使えます。

## できること

- 時代（古代／中世／近世／近代／現代）と問題数をえらんで出題
- 1つのできごとから3種類の問題を自動で作成
  - 年号 → できごと
  - できごと → 年号（近い年号でひっかけ）
  - できごと → 人物
- まちがえた問題を端末に記録し、「まちがえた問題だけ」で復習（正解すると消える）

## 問題の追加・修正

`index.html` の `ITEMS` に1行足すだけです。

```js
{ era: "近世", year: 1603, event: "江戸幕府が開かれる", person: "徳川家康" },
```

- `era` は 古代／中世／近世／近代／現代 のどれか
- `person` は省略できます。**ほかの選択肢の人物も正解に見えてしまう場合**（例：本能寺の変 → 明智光秀と織田信長）は書かないでください
- 新しい漢字を使うとその文字だけふつうの字体になります。ドット文字にしたいときは `tools/make-font.py` でフォントを作り直してください（手順はファイル冒頭）
- 内容を変えたら **必ず** `sw.js` の `VERSION`（例：`v3` → `v4`）も上げてください。上げないと iPhone のアプリは古いまま動き続けます
  - アプリは端末に保存した分で動くため、更新は「開いたときに新版を取り込み → 次に開いたときから反映」の2段階です

## iPhone に入れる方法

iPhone ではファイルを直接開けないので、GitHub Pages で HTTPS のサイトとして公開しています。
公開URL：https://clubman621-git.github.io/history-quiz/

（Settings → Pages → Branch を `main` / `(root)` にすると公開されます）

### ホーム画面への追加

1. iPhone の **Safari** で公開した URL を開く
2. 下の「共有」ボタン →「ホーム画面に追加」
3. ホーム画面の「歴史クイズ」アイコンから起動

一度開いたあとは、機内モードでも起動できます。ふだんの通信は、更新があるかの確認（1KBほど）だけです。
